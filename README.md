# Corridor Escape HTML Web Game
Make your way through the corridors, answer the questions that appear correctly, pass through 15 rooms, and win the game. If you choose the wrong rooms, you risk losing and will have to start over from Room 1. This game, which supports both English and Turkish, features questions across 4 different difficulty levels. If you complete the game within a certain time limit and at a specific difficulty level, your achievement will be recorded in the “Records” section. It supports mobile devices and works on phones, but it’s not very stable on mobile. If you play on a mobile device, your phone will likely overheat. Therefore, we recommend playing on a PC. By default, the game buttons are arranged on the screen with mobile support enabled; it is recommended that you disable this in the settings when playing on a PC. It is an open-source HTML/JS/CSS game and contains no viruses. The game can be run using the .exe file available in the “releases” section.
